# 13. 卓の一覧は gid だけを返す

- 日付: 2026-09-16
- 状態: 採用

## 背景

管理画面が卓ごとに要求を投げるのを減らすため、一覧に席と入場券を載せた時期があった。
しかしそれでは、卓が増えるほど、要らない卓の中身まで毎回引くことになる。

## 決定

- `GET /games` は gid だけを返す。
- 席と入場券は `GET /games/:gid` で 1 卓ずつ引く。`POST /games` は `GET /games/:gid` と同じ形を返す。

## 結果

- 一覧の応答は、卓の数にしか比例しない。
- 一覧を太いまま `GET /games/:gid` を戻した時期に、その口は呼ばれないまま残っていた。
  口を変えるときは、呼ぶ側（`admin.js`）も一緒に見る。
