# 7. 卓は終了時にだけ保存し、読めなければ起動しない

- 日付: 2026-09-17
- 状態: 採用

## 背景

再起動すると卓が消えていた。操作のたびに書き出すと、卓や操作が多いほど IO が増える。

## 決定

- 起動時に `data/games.json` を読み、終了時（`close`）にだけ書き出す。操作のたびにも、定期的にも書かない。
- 読み書きは同期 API で行う。読むのは待ち受けの前、書くのは終了時だけで、要求の処理中ではない。
- 一時ファイルに書いてから rename し、権限は 0600 にする（入場券と伏せた札が入るため）。
- 読めない、または形の違うファイルがあれば起動を止める。ファイルが無いときだけ、空の状態で始める。
- 保存先は `data/` に決め打ちにする（`logs/` と同じく、起動の引数で変えない）。
  テストは `store.mjs` を差し替えて一時ディレクトリへ向ける。
- 保存する項目を足すときは、無い場合の既定値を復元の側で決め、`version` を上げずに読めるようにする
  （例: `title` が無ければ `GAME <gid>`）。

## 結果

- 異常終了（SIGKILL、クラッシュ、電源断）では、起動してからの変更がすべて失われ、その間に消した卓も戻る。
  これは受け入れている。
- 空で起動すると、次の終了で壊れたファイルを空の状態で上書きして消してしまうので、起動を止める。
