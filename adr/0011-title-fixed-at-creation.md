# 11. 卓の名前は作るときにだけ決める

- 日付: 2026-09-29
- 状態: 採用

## 背景

参加者の画面の見出しに `GAME <gid>` と出していた。卓に回やシナリオの名前を付けたい。

## 決定

- `POST /games` の `title` は任意で、省略すると `GAME <gid>`（例: `GAME 1`）にする。
- 作った後は変えない。`PATCH /games/:gid` が変えるのは席の名前だけで、`title` を送っても使わない。
- `title` は `app.mjs` で入場券と並べて持つ。既定値に gid が要り、`Game` は自分の gid を知らないため。

## 結果

- 参加者の画面は、見出しの横とタブに卓の名前を出す（卓の種類の名前は見出しに出す）。
- 変わらない値なので、WebSocket の action には載せない（`GET /join` で一度受け取る）。
- 卓の名前を足す前に保存した卓は、読み戻すときに `GAME <gid>` になる（ADR 7）。
