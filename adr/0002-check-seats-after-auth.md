# 2. 席とカードの存在は認証の後で確かめる

- 日付: 2026-09-16
- 状態: 採用

## 背景

Express の `app.param` は、ルートに並べたミドルウェア（`verifyToken`）より先に走る。
席やカードが在るかを `app.param` で確かめると、トークンを持たない人にも 404 が返る。

## 決定

- 形の検査（`validateId`）は `app.param` に置く。
- 存在の検査（`validatePlayer`・`validateCard`・`validateEpitaph`）は、各ルートで `verifyToken` の後ろに並べる。

## 結果

- トークンが無ければ、存在しない pid でも 401 になる。404 と 401 の差から、席の数や手札の枚数を測れない。
- テストが、存在しない席や札でもトークンが無ければ 401 に揃うことを固定している。
