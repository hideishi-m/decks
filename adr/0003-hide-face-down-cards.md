# 3. 伏せた札の中身は、見てよい人にしか返さない

- 日付: 2026-09-16（エピタフは 2026-09-17）
- 状態: 採用

## 背景

画面の側で隠すだけでは、ブラウザの開発者ツールで中身を読める。

## 決定

- 卓の公開状態（`GET /games/:gid/table` と action の `table`）は、伏せた札の枚数だけを返す。
- action の `card` に入れるのは、場に表で出た札だけ。
- 手札の中身は、本人の pid でだけ返す。切り札も、他席には持っているか切ったかだけを見せる。
- エピタフの裏の番号を返すかどうかは、`Epitaphs.toJson(master)` の 1 か所で決め、マスターにだけ返す。
  裏にしたときの action にも番号を載せない。
- エピタフの表裏は `EpitaphCard.open`（真偽値）で持ち、タロットの向き（`position`）を流用しない。

## 結果

- タロットの山札のシャッフルは向きを無作為に変えるので、向きを表裏に流用すると勝手に公開される。
- マスターは `GET /games/:gid/epitaphs` で裏の番号を取る。表にする・裏にするはマスターだけ（403）だが、
  席同士は守らない（ADR 1）ので、誤操作よけの意味になる。
